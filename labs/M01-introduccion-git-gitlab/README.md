# M01 — Introducción a Git y GitLab

[← Página anterior](../../README.md) · [Siguiente página →](00-control-de-versiones.md)

Antes de tocar el manual, necesitas saber qué guarda Git, dónde lo guarda y qué añade GitLab encima. En este módulo configuras tu identidad, entras en la instancia del curso y creas el proyecto `manual-equipo`.

## Qué aprenderás

- Para qué sirve el control de versiones y qué es un commit
- Qué hace Git y qué hace GitLab
- Repositorio, directorio de trabajo, área de preparación y commit
- Moverte por un proyecto de GitLab
- Configurar Git con tu nombre y tu correo
