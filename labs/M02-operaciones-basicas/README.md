# M02 — Operaciones básicas con repositorios

[← Página anterior](../M01-introduccion-git-gitlab/README.md) · [Siguiente página →](00-ciclo-de-un-cambio.md)

El manual ya está en GitLab; ahora lo traes a tu equipo y trabajas con él. Cada cambio queda registrado en un commit que puedes consultar, comparar y publicar.

## Qué aprenderás

- Crear y clonar repositorios
- Consultar el estado de los archivos
- Preparar y registrar cambios: `status`, `add` y `commit`
- Consultar el historial y comparar: `log` y `diff`
- Sincronizar con GitLab: `push`, `pull` y `fetch`
- Excluir archivos con `.gitignore`
