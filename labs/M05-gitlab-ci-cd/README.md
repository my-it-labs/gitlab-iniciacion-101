# M05 — Introducción a GitLab CI/CD

[← Página anterior](../M04-trabajo-colaborativo/README.md) · [Siguiente página →](00-pipelines-stages-jobs.md)

Una página sin título o un enlace roto no debería llegar al manual. Añades un pipeline que lo comprueba en cada push y genera el manual listo para descargar, y aprendes a leer su log cuando falla.

## Qué aprenderás

- Integración y entrega continuas
- Estructura de `.gitlab-ci.yml`
- Pipelines, stages y jobs
- Qué hace un runner
- Ejecución automática tras un push
- Logs y diagnóstico de errores sencillos
- Artefactos de un job
